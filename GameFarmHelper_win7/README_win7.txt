=== GAME FARM HELPER для Windows 7 ===

УСТАНОВКА:
1. Установите Python 3.8 (последняя версия для Win7)
   Скачать: https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe
   
2. Запустите install_win7.bat
   Это установит необходимые библиотеки и NirCmd

3. Запустите start_win7.bat для запуска программы

ИСПОЛЬЗОВАНИЕ:
- Выберите "1" для быстрого запуска (монитор выключится через 10 сек)
- Выберите "2" для запуска с таймером 30 сек
- Выберите "3" для настройки своего времени
- Монитор включится автоматически при движении мыши

ПРИМЕЧАНИЯ:
- Программа работает без прав администратора
- NirCmd нужен для надежного выключения монитора
- Если NirCmd не установлен, программа использует встроенные методы
