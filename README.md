# 🎮 Game Farm Helper

Программа для автоматического выключения монитора во время фарма в играх. Экономьте энергию и ресурсы, пока ваш персонаж фармит часы!

## ✨ Возможности

- 🖥️ **Автоматическое выключение монитора** через заданное время бездействия
- 🖱️ **Мгновенное включение** при движении мыши или нажатии клавиш
- ⏱️ **Настраиваемое время** от 5 секунд до 10 минут
- 📊 **Информация о системе** (Windows, CPU, RAM, GPU)
- 🔄 **Автовосстановление** настроек после выхода
- 💻 **Поддержка Windows 7/10/11**

## 📥 Установка

### Windows 10/11

1. **Установите Python 3.11+**
   - Скачайте с [python.org](https://www.python.org/downloads/)
   - При установке отметьте **"Add Python to PATH"**

2. **Скачайте программу**
   - Нажмите зеленую кнопку **Code** → **Download ZIP**
   - Распакуйте архив в любую папку

3. **Установите зависимости**
   - Запустите `install.bat` от имени администратора
   - Или вручную: `pip install pywin32 psutil wmi pyautogui keyboard mouse`

4. **Запустите программу**
   - Нажмите правой кнопкой на `start.bat`
   - Выберите **"Запуск от имени администратора"**

### Windows 7

1. **Установите Python 3.8**
   - Скачайте [Python 3.8.10](https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe)

2. **Установите зависимости**
   - Запустите `install_win7.bat`

3. **Запустите программу**
   - Запустите `start_win7.bat`

## 🚀 Использование

### Быстрый старт

1. Запустите программу
2. Выберите пункт **1** (монитор выключится через 10 секунд)
3. Не трогайте мышь и клавиатуру
4. Монитор выключится автоматически
5. Подвигайте мышкой, чтобы включить монитор

### Меню программы
1. Запустить фарм (монитор выключится через 10 сек)

2. Запустить фарм (монитор выключится через 30 сек)

3. Запустить фарм (своё время выключения монитора)

4 Тест: выключить монитор

5. Информация о системе

6. Выход

### Настройка времени

- Выберите пункт **3**
- Введите время в секундах (от 5 до 600)
- Например: `120` = 2 минуты

## ❓ Часто задаваемые вопросы

### Монитор не выключается
- Запустите программу **от имени администратора**
- Проверьте, что Python установлен правильно
- Попробуйте пункт **4** (тест выключения)

### Монитор не включается
- Просто подвигайте мышкой
- Или нажмите любую клавишу на клавиатуре
- Подождите 1-2 секунды

### Игра останавливается при выключении монитора
- Убедитесь, что в настройках игры выключен режим "Пауза при потере фокуса"
- Запустите игру в оконном режиме без рамки
- Проверьте настройки энергосбережения Windows

### Программа не запускается
- Проверьте, что Python установлен: `python --version`
- Установите зависимости: `pip install pywin32 psutil wmi`
- Запустите от имени администратора

## 🔧 Требования

- **Windows 7/10/11** (64-bit)
- **Python 3.8+** (для Win7) или **Python 3.11+** (для Win10/11)
- **2 GB RAM** минимум
- **Права администратора** (рекомендуется)

## 📝 Примечания

- Программа **не управляет вентиляторами** автоматически
- Для управления вентиляторами используйте **MSI Afterburner**
- Для управления подсветкой клавиатуры используйте ПО производителя
- Программа **не изменяет** настройки игры

## 🛠️ Технические детали

Программа использует:
- **Windows API** для выключения монитора
- **powercfg** для настройки таймаутов
- **GetCursorPos/GetAsyncKeyState** для отслеживания активности
- **WMI** для получения информации о системе
